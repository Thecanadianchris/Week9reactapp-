# The Edge Of Nature

A React site showcasing handmade resin art and river tables, with a page-switching layout (Home / Gallery / Resin Facts) and a live facts feature pulled trough from the GitHub repo ( Not directlly from the folder ). 

## Features

- **Home** - intro page for the site.
- **Gallery** - filterable display of resin art and river table pieces, using `useState` to filter by category.
- **Resin Facts** - fetches a `facts.json` file (300 facts) directly from this GitHub repo using the GitHub REST API, picks a random selection, and displays however many you ask for (max 20, with a 3-second warning if you request more).

## Tech Used

React, JavaScript, Axios, CSS

## Running Locally

npm install
npm run dev
